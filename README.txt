A4・A3 POP面付けツール

【使い方】
1. ZIPを展開します。
2. index.htmlをダブルクリックして開きます。
3. A4・A3、縦・横、分割数、境界線、保存形式を選びます。
4. 各枠へ画像をドラッグするか、「複数画像を選択」から画像を入れます。
5. 「面付け画像を保存」を押します。

A4：2分割=A5、4分割=A6、8分割=A7、16分割=A8相当です。
A3：2分割=A4、4分割=A5、8分割=A6、16分割=A7、32分割=A8相当です。
PNGを標準・推奨形式としています。JPGは高画質設定で保存します。
印刷時に画質が粗くなる可能性がある画像には「低解像度」と表示されます。
画像は外部へ送信されず、ブラウザ内だけで処理されます。
