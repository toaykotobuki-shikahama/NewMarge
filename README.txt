A4・A3 POP面付けツール

【使い方】

1. ツールのURLをブラウザで開きます。
2. 出力用紙をA4・A3から選びます。
3. 用紙の向き、分割数、境界線、保存形式を選びます。
4. 各枠へ画像をドラッグするか、「複数画像を選択」から画像を入れます。
5. プレビューを確認し、「面付け画像を保存」を押します。

【分割後のサイズ】
A4：2分割＝A5、4分割＝A6、8分割＝A7、16分割＝A8相当

A3：2分割＝A4、4分割＝A5、8分割＝A6、16分割＝A7、32分割＝A8相当

PNGを標準・推奨形式としています。
JPGは高画質設定で保存します。

印刷時に画質が粗くなる可能性がある画像には、「低解像度」と表示されます。

ツールの利用にはインターネット接続が必要です。
選択した画像の処理はお使いのブラウザ内で行われ、画像がサーバーへ送信・保存されることはありません。
